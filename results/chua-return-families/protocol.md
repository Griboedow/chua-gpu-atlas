# Testing the return mechanism outside the first sequence

This protocol precedes new searches. The existing catalogue suggests two further candidates: S09/S10 near the five-peak S11 branch, and E03/E04 near the seven-peak E05 branch. These associations are hypotheses, not classifications inferred from peak counts alone. All calculations use alpha = 9, m0 = -8/7, m1 = -5/7, gamma = 0.

## Calibration and prospective targets

Use the two existing long references in each candidate sequence, with normalized signed half-return multiplier +1/2. Refine their fold and symmetry endpoints. Continue the proposed short organizing cycle to the beta of the second reference and measure its unstable full-period multiplier Lambda and period Tp. Preserve its itinerary, path checks and section distances. Existing gain measurements from the preceding study are calibration inputs, not new predictions.

Before any new long-orbit search, publish numerical forecasts and their source hashes. Target normalized section counts 7, 9 and 11 (n = 3, 4 and 5). The proposed peak counts are 35, 45 and 55 for the S11 sequence, and 49, 63 and 77 for the E05 sequence. Insert one full circuit of the proposed saddle into each symmetric half when extending a root. Repeated shorter orbits and invalid region itineraries do not count as discoveries.

Record both the leading and corrected forecasts. With k = n - 2 and t = Lambda^(-k), the leading forecasts are W_n = W_2 t^2, G_n = G_2/t, and T_n = T_2 + 2 k Tp. A fixed two-point correction has W_n = t^2 (A_W + B_W t) and G_n = A_G/t + B_G. Coefficients are determined only by n = 1, 2. The corrected models allow the first finite-period term; they are extrapolations, not error bounds. Do not refit them to the new targets.

Score corrected width and gain forecasts against subsequent roots with provisional relative gates 25% and 20%, and period error 0.5 time units. Report all errors, including misses and leading-law results. These are numerical tolerances, not statistical confidence intervals. The location seed extrapolates the preceding two folds with ratio 1/Lambda, but the root location is corrected by shooting and is not a point-location forecast.

## Mechanism checks

For each successful target, independently count peaks and section crossings, reconstruct the prescribed affine flights at higher precision, and compare selected returns with full-field integration. Refine gain maxima in phase and compare with denser meshes. Analyze section-point residence near the proposed organizing saddle at the same parameters. Compare the contraction of perturbations along the actual maximizing direction, rather than inferring contraction solely from a Floquet eigenvalue.

Measure a same-parameter saddle companion and the normalized nonlinear return for selected new cycles. Test the predicted companion signed half multiplier 1.5 and the secant map F(s) = (s + s^2)/2. A companion separation does not identify a basin boundary. A scalar return does not determine the knot type of an embedded three-dimensional orbit.

## Scope and negative outcomes

The existing 34 references and previous 95/105-peak tests remain unchanged. New cycles are additional targeted examples, not a complete atlas census. No global finite list of organizing saddles or new infinity theorem is assumed. If a proposed parent, itinerary, correction or scaling fails, retain the failure and narrow the explanation. The goal is a simpler description supported by comparisons between distinct sequences, not an enforced universal fit.
