# Interval certificates for three hidden cycles

[Theorem, model and reproduction commands](../../docs/chua-explicit-hidden.md). All coordinates and periods are dimensionless. Voltages in the start records have zero initial coil current.

| Records | Domain and contents |
|---|---|
| [Parameter cover](beta-cover.json) | 490 adjoining β cells. Each row bounds both primitive periods, stability and the exclusion of equilibrium neighborhoods. |
| [70-digit shooting certificate](certificate-70.json) · [90-digit repeat](certificate-90.json) | Shooting boxes, images, admissible flights and stability bounds around β = 12.23. |
| [70-digit launch certificate](starts-70.json) · [90-digit repeat](starts-90.json) | At β = 12.23, voltage rectangles enter contracting sets around the right-lobe and outer cycles. Reflection gives the left-lobe start. |
| [Independent checks](independent-check.json) | Coverage, precision comparisons, rejection controls, DOP853 and Radau periods and closure errors. |
| [Voltage projections](cycles.png) | Numerical trajectories at the nominal setting. |
